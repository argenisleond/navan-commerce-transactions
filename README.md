# Navan Commerce Transactions

A Java and Spring Boot service for storing travel transactions and creating
immutable invoice snapshots.

## Prerequisites

- JDK 21 or newer

The project includes the Maven Wrapper, so a system Maven installation is not
required.

## Run the application

```bash
./mvnw spring-boot:run
```

The application listens on `http://localhost:8080` by default.

## Run the tests

```bash
./mvnw test
```
