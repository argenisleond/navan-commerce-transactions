# Codex Efficiency Rules

## Scope
- Inspect only files relevant to the requested change.
- Do not scan the entire repository unless necessary.
- Do not modify unrelated code.
- Prefer minimal, targeted changes.

## Java
- Follow existing Java conventions.
- Preserve existing architecture.
- Avoid introducing dependencies unless requested.
- Use IntelliJ/project build conventions.

## Database
- Check SQL dialect compatibility.
- Prefer existing local documentation.
- Avoid web searches unless required.

## Testing
- Run targeted tests for changed code.
- Avoid full builds unless necessary.
- Do not repeatedly run failing commands without investigating.

## Communication
- Keep responses concise.
- Avoid lengthy explanations.
- Summarize changed files and test results.
- Ask before starting large refactors.
